# Dale's project phase rules

These requirements apply to every estimate integration and later phase.

- Build each phase as Dale defines it.
- The project intake/handoff system is a later task.
- Only actual, supported project scope belongs in an estimate.
- NEVER insert an empty division or section heading.
- NEVER populate all CSI divisions or sections simply because they exist in the catalog.
- A division or section needs supporting project evidence before an estimate entry is prepared.
- If no division or section is supported, create no estimate entry. Keep uncertainty in the review record, not as placeholder scope.
- Section entries belong beneath their verified parent division and retain their section numbers.
- No estimate delivery may be claimed before the exact target acknowledges the write.

Current live estimate connection and verified 2026 catalog are still outstanding; do not substitute another BASK site or an older catalog.
